# 阶跃：真实数据展示与截图

源码、运行数据和截图分开管理。GitHub 仓库不包含本机 `.env`、历史行情库、机器人连接、账户或分析记录；从仓库重新部署后需要自行配置并采集。

当前版本按开发快照管理，不等于生产发布验收。原生 Windows 下的完整后端测试仍有未解决项，包括 POSIX 进程接口、测试配置隔离与临时 SQLite 文件占用；本机展示路径正常不能替代这些验证。Windows 以普通文件检出符号链接时，治理检查也可能失败，需要在支持符号链接的环境复验。

## 启动与展示

Windows 在项目根目录执行：

```powershell
.\scripts\local-web.ps1 Start -NoAutomation
```

访问脚本输出的本机地址。此模式保留已保存的订阅设置，但不启动研究自动推送工作进程；手动分析仍需关闭通知选项。需要恢复自动任务时，等待当前分析结束，再正常停止、启动，不加 `-NoAutomation`。

| 页面 | 准备方式 | 截图时保留的信息 |
| --- | --- | --- |
| 首页 | 手动运行大盘复盘或个股分析，关闭通知 | 分析时间、标的名称、数据日期；规则回退不能称作模型研判 |
| 选股 | 配置完整历史数据目录，运行收盘策略 | 策略、收盘日、覆盖范围和真实候选；盘中不冒充收盘结果 |
| 跨资产研究 | 手动读取股票 / ETF 日线，保存有来源的研究假设 | 来源、最新交易日、复权及质量提示；研究笔记仅保存在当前浏览器 |
| 回测 | 对已有历史分析运行收益复核 | 窗口、样本数和原分析日期；此页不等于所有内置选股策略的组合回测 |
| 数据中心 | 实际取数后刷新概览 | 配置状态与实际成功观测分开解释，不把未验证接口当成可用 |

持仓、交易、告警和送达回执仅展示真实记录，不为截图虚构账户、成交或推送成功。资讯入库也不等于已完成模型筛选或研判。

## 常见阻塞

- `closed_session_dataset_missing` / 引用包缺失：按 [本地环境说明](local-windows.md) 配置 `SCREENING_DATA_DIR`，目录内需要历史引用包与行情库。
- `request_budget_exhausted_restart_safe`：本轮历史采集请求预算用尽；已验证批次保留，再次运行可继续补采。不能因此跳过完整性校验或把半成品当成选股结果。
- 免费模型限流：行情与规则计算可继续使用，但不会自动转收费模型。原有付费 API 仅在明确授权后使用，调用上限应包含重试。
- 某页仍为空：先确认该功能所需的真实输入、运行记录和访问权限；不要通过伪造数据库记录掩盖未完成的能力。

截图和一次性验收输出放在本机 `local/showcase/`，不提交至源码仓库。中文说明面向当前本机展示流程，未改动上游英文部署文档。

建议在桌面浏览器独立窗口截图。窄屏的候选表需横向滚动；目前选股证据提示仍较长，个股报告中间宽度的排版也需要进一步优化，不应通过删除质量提示伪装为完整数据。
