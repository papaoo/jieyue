# 投研输出事实一致性

定位：为人工研究提供可追溯候选、资讯与条件判断，不代替交易决策，不增加自动交易、通知或调度。本轮不增加付费数据依赖。

## 修复的契约

- **行情**：统一成交量为股（ETF为份额数量），金额沿用报价币种口径。Tushare旧实时接口不再把股除100；东财CN日线和实时报价的手转股，新浪/腾讯股数和海外数据不重复转换。历史库存或旧报告不批量改写；新抓取数据按正确单位落库。
- **盘中/日终**：实时覆盖最新日线前，先保留上一完整交易日；昨收优先使用同次报价pre_close，涨额、涨幅、振幅保持同一基准。缺少/非法时间、过期或旧日报价不得生成今日技术K线，亦不得回退覆盖更新的日线；它们仍作为带限制的独立报价证据保留。网页历史、通知 Markdown 和 Jinja 模板共用时间标记，附业务日期、来源时间、日期口径和是否盘中；未覆盖的日线表不混入另一日实时价格。
- **量价解读**：盘中累计量与昨日全天量不是同时间量比，不能据此下“缩量/平量/全天放量确认”结论。Agent技术工具明确日线截至日期与来源，规则分不作为盈利概率。
- **行业/概念**：摘要、表格、热点与股票主线保留业务日期和来源；自建等权聚合不包装成官方行业指数。单日排名只能证明该截面涨跌，不能证明加速、持续性或资金流入。请求日期不覆盖数据日期。
- **ETF**：保留原默认池、参数和成本；逐源拒绝25%以上异常价格跳变，继续试备用前复权数据。不自动猜拆分倍数。复用现有腾讯源按年分页，且每页必须明确返回前复权序列，防止800根上限截断。异常、风险池缺项或已配置防守资产无历史数据时，报告明确“数据验收未通过”，不发布目标权重、历史收益或参数比较。未配置防守资产仍允许原有现金规则。有效数据的缺日、上市起点及混合来源保留告警并标记 partial，而非完整认证。
- **市场宽度**：Tushare盘后按`daily(trade_date=...)`查询截面，不把`rt_k`专用通配符传给日线接口；空结果先判空，实际来源日期传递到结构化载荷和报告。成交金额从千元转亿元。
- **资讯**：行情图表主页不是新闻；同域真实新闻不被整域封禁。其他发行人公告、ETF份额变化中仅关联到目标公司时，降级背景，不当作目标公司经营事件。原有严格日期、主体匹配、来源降级不放宽。

## 使用方法与边界

刷新本地页面后重新生成报告或运行策略；旧历史记录保持原样，不会自动替换成新结论。关注数据日期、来源、告警和证据，而非只看综合分。资讯/资金/技术信号出现矛盾时应分别核对时间和判断依据。

这些检查改善输入与呈现可靠性，不能证明模型分析始终正确或策略长期盈利。新闻检索非全量公告流，免费源仍可能限流/断连；复杂除权、小幅异常、长期缺口仍需人工复核。尚未覆盖所有股票、所有Agent模板与全部海外市场。没有成熟历史结果时不显示验证胜率。
