# 严格收盘选股与固定回放

固定回放的摘要预览/人工发送是独立入口 `scripts/send_screening_backtests.py`，具体命令与一次性回执语义见 [飞书研究投递](feishu-research-delivery.md#固定回放摘要独立人工审核-cli)。计算/采集入口本身仍无发送行为。只有六件内容哈希、manifest/配置/策略版本/源码闭包、320格矩阵和所呈现完整cohort全部通过才可审核卡片；后续计划格未成熟可保留待成熟计数，历史未知/缺失不作为现金且不向群发送状态卡。所有完整固定窗口一并汇总范围，不挑最好窗口；每策略计算评价，不复用全局分类。预览只读既有投递订阅映射，不读vault或环境，完整底层产物不删除。

十个内置策略 2.1 共用实际 `screen()` 排序逻辑、CAPCO 大类行业、300 个日历日（含边界）历史窗口及 SMA RSI。严格页面只使用最近完整收盘日；实时行情展示不变。旧自定义策略兼容行为不变。

## 数据与参考证据

普通入口沿用 `SCREENING_DATA_DIR`（未配置为项目 `data`），读取 `historical_references/` 与 `screening_history.sqlite`。首次缺少引用包/历史必须显式初始化，禁止退回供应商现时行业。日常刷新仅补新闭市日期；日期必须同时完成 daily、daily_basic、adj_factor、stk_limit、suspend_d 批次才推进 freshness 水位。局部失败下次复用已成功批次，默认一次最多100次请求；落后过多时使用显式采集命令续跑。不在页面调用中重新下载全部历史。未知/缺失不会返回陈旧结果冒充今日。

采集生命周期分三层：原始 `attempts` 追加保留每次短响应的哈希/下载时间；通过跨批次覆盖和主字段资格检查才成为不可变主批次；必要PB修复完成并再次通过严格资格才写入该引用版本的 `date_state=complete`。空/部分尝试不命中成功缓存，下次有界调用重新取得；PB中断只重试补源，不重取或重标已验收主批次。预热期只检查原始行情覆盖，不要求尚未发布的CAPCO分类，也不为预热评分补PB。没有日期完成标记的旧缓存不被当成新鲜数据，需显式采集重新验收；冻结接受证据不覆盖。源代码闭包（含scorer/config/models/normalize/selection、readiness与序列化）及Python/pandas/numpy/PyYAML版本进入运行身份，改变后不能在同一输出目录续算。

预热原始覆盖与信号/成交资格是不同范围：在固定首个信号日之前，先按当日上市池核对 daily 和 daily_basic 行是否齐全，仅缺行证券必须有明确全天停牌证明。行齐全但 S/R 时段冲突的证券仍保留原始行情与事件，不转成“无停牌”“全天停牌”或“可交易”。这类日期的 complete 仅表示原始预热覆盖完成；SQLite `artifacts` 键 `warmup_event_timing_v1:YYYYMMDD` 明确记为 `scope=raw_warmup_only`，保留引用包哈希、原 suspend_d 批次哈希、证券代码、原事件及事件哈希、固定未解决错误码，可用只读 SQL 查询。原有行情/因子覆盖、原始结构/身份/日期和哈希检查不变。缺日线或基本面时不能靠冲突事件豁免；信号资格、执行和历史缺棒校验仍调用严格解析器，未知时段仍阻断相关判断，不从原始预热 complete 推导可成交或现金回收。

引用包原件与市场 SQLite 分离。`manifest.json` 绑定原件 SHA256、原下载完成时间、URL、计划哈希及派生包哈希；`bundle.json` 绑定分类 PDF、发布日期公告、分类指引、别名、交易所日历原件及北交所周一至周五规则。复制缓存原件必须提供原 `fetched_at`（含时区），不能使用文件修改时间或现在时间。派生事实的 `derived_as_of` 与原件 vintage 分开；正式采集只新建 reference_derivation 引用记录，不重标原件时间。市场报价/基本面/备用 PB 仍要求正式采集当日取得，不放宽原来的同日发布门禁。

示例引用计划经过人工来源核验，程序验证父哈希、PDF 行数、分类码/重复值、截止日、公告延迟规则、日历完整年覆盖、BSE正文节假日范围及2.3.1周末规则。元数据发布日期来自已核验公告，不是把报告期末当发布日期；这是有来源的重建，不是对未修订历史快照的保证。新增来源计划需重新核验公告元数据。

示例覆盖：CAPCO 2025H1（5413行，2025-09-30发布）、2025H2（5463行，2026-04-03发布）、2026H1（5521行，2026-09-30发布）；各报告自发布后首个交易日起使用，年内优先最新已发布报告。SSE/SZSE/BSE 日历仅2025、2026年，引用有效边界2026-12-31。不能据此声称2027或后续公告永久新鲜。更新时使用新的不可变包目录并核对新增公告、日历及覆盖范围，再由维护者安装到运行默认目录；旧回放保留旧包及计划。

历史上市状态用 L+D+P 和半开区间 `[list_date, delist_date)`：上市日起含，终止上市生效/摘牌日起不含。`delist_date` 不是最后成交日；期间后来退市的证券仍保留在其较早上市日期的样本中。ST/退市整理用发布日期及生效区间，不能从今天的名字倒推。全日停牌要求完整 suspend_d 批次中 S + 明确空 timing 且无复牌/日内时段冲突；部分停牌仍可形成收盘信号，但对应开盘/收盘不能成交。整行缺失、字段缺列和未知数据缺口阻断；明确当日 PE_TTM null 是 `ineligible_pe_not_reported`，不填零、不推断已验证亏损。已证明IPO/ST等不合格不要求无关评分字段。300日历史缺棒也必须有全日停牌证据。证券池成员资格不等于可成交证明：摘牌日不再要求该证券形成新信号，但既有持仓仍须独立成交证据，不从退市或缺行情制造卖出/现金回收。

`suspend_d` 是事件表，不是互斥日状态。同一证券同日的 R/明确空时段与有效 S/日内区间可并存，合并为 partial；只按 S 时段判断开盘/收盘阻塞。例如 `09:30-09:41,09:44-09:54` 阻塞开盘，不阻塞收盘，仍必须有当日行情，不能解释整日缺棒。多个有效 S 区间按并集解释，重复区间不改变判断；原始采集分页重复检测不因此放宽。S/全天与 R/无明确时段仍冲突；R/非空时段未受支持，格式错误、非法时分或缺列仍不能认证时段；需要时段判断的信号/执行/缺棒路径继续阻断。正式采集与回放使用同一解析器，不新增成交时点或补现金规则。

历史主表可能包含旧式 `T` 加六位数字的 SSE 退市身份。只有 D 状态、symbol/交易所一致、有效且不矛盾的上市/退市日期、退市生效日不晚于固定矩阵最早预热边界（2025-03-11）及本次更早采集边界时，才作为显式期外记录保留；等于边界也已不重叠，晚一天则拒绝。原始身份和整行仍在不可变 stock_basic 批次及 master 中，不截去 T、不映射为同数字证券；请求日期若与该半开生命周期重叠仍阻断。正常六位代码的后来退市证券仍按同一半开区间保留早期样本。

广域 namechange 是参考表，不是证券池。原始参考行全部保留；只有经 L/D/P 主表或官方别名可联结的身份参与名称区间核验，未联结的有界 opaque 身份不转成证券，也不能补齐真实证券缺名。逐股修复响应同样必须联结到请求证券；真实名称缺口仍阻断。采集 SQLite 的 `artifacts` 表键 `legacy_listing_scope_v1` 提供可查审计：`coverage_start`、期外主表 `records`、绑定期外主表的 `name_records`、未联结的 `unmatched_name_records`，每条含原行、行哈希、原始批次哈希和原因。可通过只读 SQL `SELECT raw FROM artifacts WHERE key='legacy_listing_scope_v1'` 查看；原件及所有历史批次仍保留。此契约修复不代表真实源全量验收已完成。

PB只允许既有当日基本面行的显式null，用SH/SZ同日未复权BaoStock pbMRQ补齐；原始close误差≤0.005元、PE误差≤0.0001、代码日期一致，保留有限有符号值与独立字段来源。BJ、矛盾、整行缺失或其他字段不泛化回填。分证券有界范围缓存备用原始行及下载时间。

## 显式初始化与重跑

复制并审核 `docs/screening-backtest.example.json`。路径相对命令工作目录；不含凭据。可以把单个来源改为 `{url,path,fetched_at,sha256}` 使用已核验原件；远程来源真实重新获取时记录本次实际时间。禁止把旧原件改标成本次下载。

以下为需维护者授权的命令模板，本文实现验证没有执行在线命令：

```powershell
python scripts/backtest_screening.py --config docs/screening-backtest.example.json --output-dir local/backtests/frozen-20261016 --hydrate-references --fetch --env-file <approved-env-file> --max-requests 1000
```

配置先写入输出目录 `config.json`，才获取引用或行情。默认分页5000、最大100000行/批、HTTP超时15秒、最多3次瞬态重试、请求间隔0.4秒；权限/限频响应立即停止，实际账户限制优先。预算用完退出、保留已完成批次与配置；同命令可恢复，不能在相同输出目录更改规则、成本、截至日或引用计划。1000只是单次安全预算，不保证完成全量。不要购买权限或自动升级额度。备用PB范围调用也计入预算、20秒caller timeout；无发送代码。

原件齐全时可不传 `--fetch` 而使用 `--hydrate-references` 离线构包。已有包与SQLite的纯计算命令不读取env、不访问网络：

```powershell
python scripts/backtest_screening.py --config docs/screening-backtest.example.json --output-dir local/backtests/frozen-20261016
```

`run_backtest(config, dataset)` 只接显式数据对象。SQLite按日期存原始批次、校验哈希，按证券日期索引，工作集为一个信号日；特征跨策略按证据哈希复用，成功信号按完整输入/配置哈希缓存。禁止把原运行库作为回放库。

同一信号日的策略现在共享一个惰性历史映射，仅缓存成功组装结果，默认保守计量上限128MiB、LRU淘汰，返回帧及嵌套来源信息均为防御副本。日期、精确快照价格、引用内容与数据库generation限定复用；外部提交、同连接源写入或schema变化清空缓存，读取途中变化阻断。本类已成功提交且仅改一行的派生artifact写入不计为源变化；外部artifact提交仍保守失效。下一日使用新映射，不跨日信任原始数据。preview的日期/数值/来源校验及内容哈希、实际单一screen评分仍每次执行，无trusted跳过。日期字符串纯解析各有4096项有界缓存，不缓存当前时间、交易日历或源状态。以上是重复工作收敛，不是完整吞吐保证；实测首日6441访问/2739并集最多约2.35倍组装复用，首次组装及逐策略验证仍有多小时风险。

### 可选的按信号日进程并行

默认仍串行。纯计算可显式加 `--workers 1` 至 `--workers 6`；配置等价字段为顶层 `execution_workers`，只接受整数1–6，显式1也使用spawn子进程。该运行方式及新计算模块纳入冻结身份；更换方式需要新输出目录，不改变策略参数，也不增加环境变量配置。

父进程在采集完成后用SQLite backup API建立输出目录内独立的 `replay-input.sqlite` 与 `replay-input.json`。失败时保留供审计，同路径不覆盖不同/不完整快照。父子分别以mode=ro、query_only和已固定且不可释放的读事务重新验证批次、实际索引原文、接受日期状态及引用/实现/策略身份；原可写连接仅由父进程存取已有selection artifact。普通可写库活动事务仍禁止memo复用并清理派生缓存，不用只读标志或DataFrame attrs跳过校验。

Windows spawn最多6进程，每进程一次只算一个信号日，同日历史缓存128MiB有界；在途任务/结果不超过worker数。子进程数值库线程设为1，启动后还原父环境；不读取env文件或调用provider。每日各策略仍调用同一preview/评分，父进程按原日期/策略/持有期/入选顺序做成交、归并、artifact写入。子进程不能写输入/产物；错误、超时（单次接收上限1小时）、缺失或异身份结果直接中止，不变成空信号/现金。重启复用已验证成功selection。

这两个本地快照文件不属于七件签名产物，不改变投递路由或manifest文件集合。并行初始化需每个进程独立全量验证，增加磁盘、启动与内存成本；128MiB是每进程保留历史缓存上限，不是进程RSS上限。最多6进程不保证6倍加速或分钟级完成，应按机器余量选择并实测完整任务吞吐。

## 固定解释口径

10策略 × 4开始日（2026-01-05/04-01/07-01/09-01）× 1/3月 × 3/5/10/20交易日 = 320格。各窗口从开始日（含）到加月份日期（不含），首五只固定各20%；不足/已知开盘买不到的仓位留现金，不替补。D收盘信号、准确D+1开盘买入，第H个持有交易日收盘卖出，交易所日历索引且H≥2；不能把缺失买入日移到下一有行情日。

开盘涨停/相应停牌不买；收盘跌停/相应停牌延后到首个已证明可卖收盘。未知行情/因子/涨跌停信息不能前填。引擎支持附明确证据的无涨跌幅限制记录；生产适配器目前不从空 stk_limit 推导无涨跌幅限制，因此这类未解释记录保持不完整。

原始价格判断成交，同源复权因子计算经济收益。每侧佣金3bps+滑点5bps，卖侧另税5bps；双摩擦敏感性复用相同选择和成交。假设分数权重、不模拟整手/最低佣金；不是实际费用保证。CSI300价格指数按每个实际成交槽的进出端点比较，现金仍现金，缺失基准为null，非红利匹配alpha。

每格须有全部计划信号及成熟结果才给完整headline收益，未来/未知仍显式列出；不以部分幸存交易补齐。报告计划/有效/成熟cohort数、现金阻塞/未解决数、均值、中位数、正收益比例、最差cohort、双成本及基准差。行业暴露按策略/证券/信号日去重，不用重叠窗口/持有期扩充样本数。没有NAV、回撤、换手率、年化或因果归因。

输出七件：`config.json`、`data_quality.json`、`metrics.json`、`signals.csv`、`trades.csv`、`report.md`、`manifest.json`。分类提前固定为证据不足/完整窗口均正/完整窗口均负/混合；基准可比较格数单列。只要任一完整格缺少基准比较，整体评价即为证据不足，不能仅用可比子集宣称完整窗口均正/均负；未知基准保持null，不填零。卡片逐持有期披露基准范围的可比/完整格数。它是当前规则的回顾性重放，不是当时真实决策或未经样本内调整的样本外证据，不保证未来收益。
