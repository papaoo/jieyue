# 阶跃登录页 V2：金融装置视觉提案

2026-10-10。状态：研究与设计提案，等待用户选择路线。可读性修复和恢复旧版配色已经实施；不把它们称为 V2 完成。未修改认证、密码、服务器配置或部署。

## 已修复的真实问题

- `LoginPage.css` 把 `--login-input-fill` 指向背景变量，而 `index.css` 将该值用于 `-webkit-text-fill-color`。结果是已输入文字和密码圆点被背景色覆盖，单纯检查 CSS `color` 或 React value 都发现不了。
- Chromium 回归修复前，深色输入字符对比度为 1:1；浅色 placeholder 对比度约 4.23:1。修复将 fill 指向文字色，placeholder 指向 secondary text 并明确 opacity=1。
- 恢复蓝色版之前的石墨底、浅灰绿按钮和暖红 / 薄荷绿 K 线。保留已经简化的文案和可暂停场景；不是整体回滚仓库。
- 新增 `e2e/fixtures/login-readability.spec.ts`，真实浏览器覆盖深浅主题 × 登录/首次设置；检查提示文字、密码圆点、切换明文、确认密码、桌面/手机布局。API 全部是明确 fixture，不提交真实密码。

## 现有视觉审视（设计判断，不是客观评分）

当前 K 线大多是相似尺寸的小图元，整体仍像一张被倾斜的二维图表；没有大尺度前景、遮挡、材质高光或镜头焦点。连续平移、扫描、聚焦、成交量起伏各自循环，缺少统一叙事。品牌区和表单是两个独立块，画面缺乏贯穿它们的视觉主线。

用户明确不认可上一轮蓝色版。“大厂质感”在本任务中落实为：显著的构图主次、可信材质、统一动效节奏、清晰输入反馈、可靠降级和每一状态可读性；不作为已经达到的宣传结论。

## 路线 A：电影感金融装置（推荐，待确认）

### 构图与材质

- 保留当前石墨中性底。红绿只出现在金融主体的局部边缘或内芯，辅助界面用银白和克制的灰绿。
- 前景 5–7 根大尺度立体 K 线，具有倒角、明暗面、柔和反射和细微表面纹理；从左下向中上形成斜向走势，局部出画制造尺度感。不复制参考站圆柱外形。
- 中景用更细的价格轨迹、量能层；远景用低对比网格和流动深度。遵守近大远小、真实遮挡、统一光源，不均匀撒粒子。
- 桌面主视觉约占可用宽度 60%，表单约 40%。保持无横向溢出；主视觉可越过自己的内框但不能覆盖输入或点击区域。品牌与场景共用一条构图轴线。
- 手机单独设计短幅构图，保留最有辨识度的 3–5 根主 K 线，压缩后景；不将桌面海报等比缩成小图。

### 动效分镜（提案）

| 时间段 | 主动作 | 次动作 |
| --- | --- | --- |
| 0–1.2 秒 | 主 K 线错峰形成，品牌与表单入场 | 后景刻度淡入 |
| 1.2–4 秒 | 走势向下一组 K 线传递，材质高光移动 | 量能跟随同一拍点 |
| 4–7 秒 | 镜头轻微推进，前后景产生视差 | 局部价位指引出现再消失 |
| 7–10 秒 | 重心回归，过渡到循环起点 | 深度层与高光收束 |

入场只播放一次，循环场景不反复触发表单入场；前 3 秒应能看见主体动作，而非只看见扫描线。鼠标视差幅度小，不模拟页面倾倒。输入聚焦时，装饰运动减弱以让文字更容易追踪。使用合成图形，始终标注非实时演示，不出现伪造收益、推荐信号或“已连接市场”。

### 技术取舍

优先评估“原创预渲染视频 + 本地封面 + 轻交互层”：适合固定镜头、材质细节和手机降级，接近已观察参考块的技术形态。静音、playsinline、加载失败 / 关闭动效 / reduced-motion 时用完整静态封面；离屏和后台暂停。不得阻塞登录表单挂载和输入。

视频需先完成原创制作方案并生成可审核样片；不默认有版权、不默认已有素材、不自动购买或调用付费生成服务。目标桌面素材约 3MB 以内、独立手机素材，属于预算目标而不是已测性能。

若需要真正响应鼠标的镜头和材质，可选懒加载 Three.js / React Three Fiber。它需要依赖、资源清理、上下文丢失兜底、DPR 上限、性能实测；暂不安装。基于用户对样片的选择，再确定这一步的技术，而非先把重依赖放入登录链。

## 路线 B：专业交易终端（备选，待确认）

用多层行情窗、K 线/成交量/深度联动、短时更新高亮构成视觉主体，规模和密度比当前场景更强。尽量使用原 React / SVG / CSS 栈，实现成本和维护成本较低。它偏工具与分析工作台，材质冲击力弱于 A。仍不能冒充真实报价或已接入数据。

## 不改动的契约

`useAuth.login(password, confirm?)`、首次设置、站内安全 redirect、显隐、禁用/等待/错误、主题与语言、动效偏好持久化保持原样。表单仍为真实 HTML input / button，不画进 Canvas，不接管用户粘贴或密码管理器行为。
