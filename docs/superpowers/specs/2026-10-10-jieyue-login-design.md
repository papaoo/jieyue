## 设计

采用不对称品牌舞台与访问面板。1440×900 桌面左侧金融视觉、右侧独立表单；390×844 手机收为短幅舞台。保留 min-height:100dvh 和自然滚动。

- 主视觉：原创周期性 SVG K 线、影线、成交量柱及分层走势。双 tile 连续横向移动，配合扫描光束、聚焦脉冲与缓慢透视镜头；追加错峰成交量呼吸、沿走势光点和深度分布层，不依赖鼠标才会动。
- 数据边界：合成演示，不请求股票数据，不出现股票代码、报价、收益或交易信号；仅保留可见标注“市场演示 · 非实时”。蓝色 K 线是品牌插画，不将该装饰色映射推广为真实行情涨跌色。
- 色彩：按用户继续打磨的要求，深海蓝 #091525、面板 #112238、银白 #eaf3ff、冰蓝 #a7cefa、按钮 #c2dcfb；K 线使用冰蓝与钢蓝。浅色用雾蓝 #edf3fb，保留独立主题。
- 文案：保留品牌名及“洞见市场，专注研究”；欢迎回来 / 管理员密码说明 / 进入工作台。移除重复口号、英文技术标签与访问编号，保留研究风险提示和真实协议警告。
- 字体：现有本地系统字体栈，中文可用字体优先；技术小字使用系统等宽字体。不复制案例商业字体，不新增字体下载。
- 品牌：中文阶跃、拼音 JIEYUE、缩写 JY；原创新阶梯标识用于页眉与 favicon，不再充当主舞台。
- 表单：双层边框、清晰密码标签、键盘聚焦与显隐、真实等待和错误状态。协议提示来自真实 HTTP / HTTPS。

## 工程边界

沿用 useAuth.login(password, confirm?)、首次设置、受限站内 redirect、SettingsAlert、主题 / 语言 / 动效偏好。兼容旧动效持久化键。

StockMarketVisual 与认证隔离，无 WebGL、外站视频、播放自动许可或新增依赖。关闭动效、系统 reduced-motion、后台及离屏时停止 CSS 动画并保留完整静态 K 线；卸载清理监听与 Observer。CSS 透视可能使用浏览器 GPU 合成，因此不声称“无 GPU”。

旧液态材质组件、专属测试和本轮新增 Paper 依赖已移除；不是回滚其他原有工作。
