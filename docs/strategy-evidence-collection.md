# 策略证据采集契约 v2

正式研究只在完整限定样本完成后发布，不代表全市场或完整全因子版本。预览的 `technical_limit` 保持调用兼容，但不再裁剪依赖分母；生产采集的 `batch_size`（默认 100）才是每次工作预算。所有快照合格股票共同计算分位数、技术评分、风险和后置评分，之后取 Top N。零候选是合法完成结果。

覆盖契约新增 `contract_version=2`、`evaluation_scope_count`、`evaluated_count`、`pending_count`、`failed_count`、`scope_hash`、`strategy_dependency_version`。只有待采与失败都为零、已评估等于完整范围，且计数、哈希及逐股证据相符时才可发布。旧冻结报告仍按原契约读取；新契约不以 100 只作为有效性上限。

## 同日恢复与安全边界

首次采集冻结市场表、日期/单位元数据、股票交易所映射、研究背景和原始证据；后续不会重新拉取市场表后拼接不同快照批次。断点由现有 EvidenceStore 保存不可变内容哈希文件，原子指针只记录哈希。身份绑定业务日期、完整策略配置哈希、依赖版本、快照及联合股票池哈希。完成的策略退出本次待处理列表，不影响其他策略复用原先联合池。策略配置变化使用新身份；跨日不复用。

恢复先校验断点和所有原始证据哈希、业务日期和获取时间。校验失败阻断，不静默重新初始化。哈希检测损坏，不是对能改写整个本地存储的攻击者的认证，也不证明行情真实性。断点不包含凭据或任意异常文本，原始接口字段与错误码均有白名单。发布仍保留原来的当日获取证据与时间窗口要求。

每次采集会话在读取断点时取得新的写入代际（首次初始化也一样）。每个断点键由操作系统文件锁保护，写入在锁内核对代际并使用唯一临时文件替换指针，旧会话无法覆盖接管者的进度。自动工作器另在指针发布时持有与租约接管相同的 SQLite 原子事务；该事务只包围本地文件操作，不包围数据源请求。

发布端从已校验的冻结快照重新计算当前策略的完整候选范围与联合池，并核对当前策略目录/依赖身份，而非仅比较生产者提交的计数或自行计算的哈希。因此，协调缩小代码列表、计数及哈希仍不能绕过完整范围验收。

未耗尽的正常分批工作使用现有 `retry_wait` 状态与 `collection_pending` 阶段/错误码，当前成功进度不扣源错误的三次重试预算。权限、结构/身份/日期错误仍阻断；超时、限流等真实暂态错误仍有界。未完成批次不进入解释、发布或发送链路。无调度器配置或启动行为变化。

待采/失败计数按任务持久化到独立 `research_automation_progress` 表，只保存白名单覆盖计数，状态查询和工作器重启后均可见；它不是 ResearchBatch，不能用于发布。已有批次就绪后，状态查询优先显示批次覆盖数据。该表通过现有建表流程增量建立，不修改已有任务表或历史报告。

## 行业、股息与上市资格

统一字段为 `industry_taxonomy`（含版本，如 `capco_major_v1`）、`industry_code`、`industry_as_of`、`industry_source`、`industry_evidence_id`；`industry` 仅是显示名称。分组需要全部字段且生效/已公布日期不晚于信号日，按命名空间与代码精确分组。严格策略不回退 LLM 行业猜测、旧 provider 字符串或子串别名。缺失标为 `industry_unassessed`；已知行业只执行现有软集中度惩罚，不引入硬仓位上限。历史/legacy 调用保留旧展示与分组语义。

Task 3 已实现 CAPCO 公开分类参考适配器，正式采集与回放使用同一版本化参考包，保留分类生效/公布日期与源版本。实现和离线测试不代表实盘覆盖验收已完成；实际全证券/日期覆盖、源权限及源版本限制仍须独立验收。新的 v2 市场背景及其证据恢复不会把旧 `stock_basic.industry` 聚合伪装成规范分类。

预览只校验所提供数据的结构与元数据，不独立认证原始响应、单位转换或交易所会话覆盖。规范行业元数据完整时参与实际风险分组；正式采集适配器另外核验 300 日窗口内的开市会话，缺失日线必须由完整停牌证据解释，部分时段停牌不能解释整日缺口。历史保留 daily、adj_factor 与按需 suspend_d 的明确引用，断点恢复保留这些引用；发布使用既有 adj_factor 父证据身份，不接受任意哈希。上述适配器保障不等于 MACD 完全收敛、来源真实性认证或实盘验收完成。

停复牌表允许同一证券同日多条事件，逐行身份和日期仍核验。共享解析器将 R/明确空时段与有效 S/日内区间视为 partial，而非互斥状态冲突；它不能解释整日缺失行情。全天 S 与 R 的不明确冲突、非空 R 时段及格式/时分错误仍阻断，不从缺失或复牌事件推断全天可交易。

### 独立停牌补证

默认事件解析仍拒绝全天 S 与 R 的不明确冲突。仅在 SH/SZ 精确证券/日期同时出现 S、R 且时段均明确为空、primary 日线确实缺失时，显式采集可请求一次 BaoStock 当日原始状态：必须唯一精确记录、`tradestatus='0'`、成交量额为空字符串，且四价均为相同正有限数。四价只是停牌占位一致性核验，绝不填入行情、收益或成交；`tradestatus='1'` 不能反证无停牌，BJ、身份/日期矛盾、未更新、缺记录或其他未知仍阻断。已有日线时不能用此补证消解冲突。

历史采集补证计入总请求预算并保留间隔、20 秒超时、原始 attempt；验证成功才进入不可变 accepted 批次，失败不成为永久缓存。正式采集每轮独立补证最多 `batch_size` 次，当前市场与缺失历史会话使用相同校验。证据 `business_date` 是正式采集业务日，`requested_date` 是所核验的当前或历史会话，原件保留获取时间、哈希以及 primary 停复牌/日线父引用。断点复用已验证原件；publisher 重新核验双方原件哈希、请求范围和停牌条件，历史父身份仍是 adj_factor。历史快照排除保留双源链接；纯回放、历史缺棒及执行状态仅读取保存的证据，不联网。执行仅返回已停牌，不制造可成交价格。本契约已做合成离线验证，不代表真实采集验收完成。

补证候选另允许一种精确原始事件形状：同时有 R 和 S，所有 R 时段均为 null、所有 S 时段均严格为 `09:30-09:30`，且 primary 日线缺失。默认解析器仍拒绝该零长度时段；必须通过上述完整独立状态补证才确认停牌。其他等长区间、混入空/部分/其他 S 时段、R 空字符串的新组合都不适用。此扩展不把零长度时段本身解释为停牌或可交易，也不改变占位价格禁入行情/成交的约束。

普通时段统一接受ASCII 1–2位小时、固定2位分钟，使用整数分钟比较，`9:30`等价`09:30`；原始字符串与哈希不改写。各交易所的有效逗号多段、无序/重叠/重复区间按原规则判断开闭市阻塞。另支持仅S事件、每事件仅一个且规范化后相同的跨会话区间：起点在09:30之后、15:00之前的实际交易时段，终点为下个开盘09:30。它只证明当日partial、开盘未阻塞/收盘阻塞，不能推定后来会话已复牌；后日状态必须独立核验。与日内区间/R事件混合、其他倒序、零长、非法时分仍拒绝；partial仍不能解释整日缺行情，不新增全日停牌补证条件或成交规则。

`dv_ttm` 保留为 `dividend_yield_ttm_pct`，单位 percent，日期由 daily_basic 独立标注；传入 Pick 的可选股息另带 `dividend_yield_ttm_as_of` 和 `dividend_yield_ttm_unit`。缺失不是零，也不阻断未依赖股息的策略。

近期上市股票的排除基于独立核验的上市日期与逐日完整交易所日历，证明上市后不足 61 个开市会话才记为 `ipo_fewer_than_61_sessions`，保留上市/日历证据和计数。150 个自然日只是日历查询边界，不用于近似股票年龄；较老股票须在已核验区间内证明至少 61 会话。成熟股票日线不足仍是数据失败。该资格检查不声称行情本身连续或 MACD 已充分收敛。

主题因子缺少已核验板块数据时继续明确披露证据受限，保持原权重和现有中性回退，不静默重新分配权重。短卡标明限定研究结果，不能宣称完整全因子版本。
