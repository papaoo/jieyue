# 阶跃免费模型通道

入口：**设置 → AI 模型 → 免费模型**，或 `/settings?category=ai_model`。

默认模型为 `deepseek-v4.1-flash-free`；另提供经过协议筛选的 MiMo 候选。
“刷新目录”核对 OpenCode 模型列表与 models.dev 零价格；“测试连接”实际发送公开的 OK 测试问题。
目录收录不等于连接成功，近期结果和用量会持久保存。支持启用前测试。

启用后，新任务的个股分析、大盘复盘、问股、图片提取和研究推送研判使用同一免费通道。
现有模型供应商和密钥不改写，关闭开关后新任务恢复原配置。已开始的任务保留原路由。
免费调用失败不会自动改用付费模型；严格规则选股不因此增加 LLM 打分或改变排名。

配置：

| 配置 | 默认值 | 说明 |
| --- | --- | --- |
| FREE_MODEL_ENABLED | false | 发布默认关闭；本机可按管理员要求开启 |
| FREE_MODEL_NAME | deepseek-v4.1-flash-free | 实际上游 ID |
| FREE_MODEL_DAILY_REQUESTS | 100 | 本应用北京时间每日请求上限，包含测试、失败与每轮 Agent 调用 |
| FREE_MODEL_MAX_TOKENS | 8192 | 单次输出上限，最大16384 |
| FREE_MODEL_TIMEOUT_SECONDS | 90 | 单次最长时间，最大180秒 |
| FREE_MODEL_PROXY_URL | 空 | 免费通道独立 HTTP/HTTPS 代理；只影响模型目录核验和模型请求 |

现有飞书研判每日额度独立保留，两者同时约束推送。上限为本应用保护配置，不代表上游承诺。
最多两个同时运行的请求，SQLite 事务预留次数；用量未返回时记为未知，不虚构零 token。
状态存储在 DATABASE_PATH 同目录的 `*.free-models.sqlite`，不保存提示词和密钥。

接入使用服务端固定 HTTPS 地址、公开通道凭据、稳定会话标识与每请求独立 ID。
通道默认 HTTPS 直连，不继承进程的 HTTP_PROXY/HTTPS_PROXY。直连受限时，可在设置中填写 `FREE_MODEL_PROXY_URL`，统一目录和调用出口；不会修改其他行情源的网络配置，也不会绕过零价格校验。
纯文本请求禁用占位工具；问股只接受其原有运行时提供的工具名，不新增 shell 权限。
上游始终 SSE，适配器校验结束标记、终止原因、响应上限，正文流复用原有分析进度接口。
本次不另建聊天/思考 UI，也不自动重试未完成的免费响应。
当前适配使用 `reasoning_effort=none` 快速模式；协议占位工具即使出现在工具声明中也不接受执行。

管理测试和刷新目录需管理员登录及同源请求。测试不会计算策略或发送飞书。
免费模型供应、地区和限流可能变化；真实投研内容会发往该第三方供应商。

协议参考 ShuYu2《Free-Model-Integration-Guide.md》（2026-10-18）及
FishBottle7/opencode2dsh commit `06a702931abcb7505147e848bf817f577f1cd577`。
许可保存在 `third-party/opencode2dsh.LICENSE`。不复制数语的计费、会话或用户系统。

回滚：关闭免费开关即可恢复原模型配置，不删除原数据；需要移除代码时只回退本次相关变更。
