# 数据补全与投研证据边界

## 本轮行为

- 最终建议：大盘风控降级后，同步 summary / buy_reason / dashboard 评分与建议 / phase immediate_action。原始模型文本存入 `dashboard.decision_audit.original`，只供审计；不是当前建议。不批量修改旧历史。
- 概念榜：先尝试免 Key 新浪概念分类快照，再回退原数据源；两者分类口径不同，不合并为同一指数。保留来源、获取时间、未知业务日期和口径。内存缓存过期且接口失败，可展示一天内最近成功的快照，但标注缓存背景，不刷新获取时间。进程重启后缓存不保留。AKShare 上游无 TTL 快照缓存由本系统刷新时清理。
- 关联板块报告：概念名称相同不代表成分口径相同。只有来源一致且有当日业务日期的快照才展示当前概念信号；缺日期、过期、不同来源或未核验成分关系只列为同名背景，并展示来源/获取时间/口径。既有无元数据概念结果也遵循此规则。
- 公告：综合情报的公告维度优先读取有界单页东财单公司公告；失败/为空时尝试巨潮。响应发行人代码必须匹配，不能只凭请求参数或摘要出现目标公司。数据仅公告元数据与原文链接，不等于已读全文、已量化经营影响，更不是全量公告服务。整版报纸页剔除；主体不确定的公告降级背景。事件检索与普通新闻共用时间窗口、关联分类及准入规则。Agent 同时收到分类、依据、发行人和原文链接。
- 筹码：仍为 Tushare / AKShare 原有数据源，没有新增付费源或不透明远端插件。Tushare 正确标记来源，并使用实际响应交易日获取同日收盘；管理器对各源等待限时并区分禁用、不支持、权限不足、超时、空数据、数据异常。有效值附日期/来源，不能当成真实账户持仓或未来胜率。旧/无日期值只作背景。
