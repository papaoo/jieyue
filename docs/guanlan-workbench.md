# 观澜研究工作台：阶段一使用与实现记录

日期：2026-10-09。工作品牌为 **观澜 / Guanlan Research / GL**，可在 `apps/dsa-web/src/config/brand.ts` 集中修改。原项目许可证、上游资料链接、API 与旧存储标识仍保留。

## 本地使用

1. 打开 `http://127.0.0.1:18080`，使用已有管理员密码登录。
2. 左侧“跨资产研究”切换 A 股、美股、黄金、BTC 的研究视角。来源概览只读取现有能力与质量记录；已配置与成功观测分别展示。
3. “按需读取日线”点击后才读取现有行情源。A 股默认 `510300`，美股默认 `AAPL`；黄金展示 `518880` 黄金 ETF 代理，不能当作现货金价。BTC 直接行情在本阶段尚未接入，读取按钮停用。
4. 研究假设簿按资产分别保存“研究假设、可观测证据、失效条件、日期”。点击“保存到本机”才写入浏览器，支持 JSON 导出。所有资产的未保存修改都会参与离开提醒；确认放弃、退出或认证失效仍可能丢弃草稿。它不随服务器账号同步，清理浏览器数据可能删除记录。
5. 左侧可折叠导航，切换深色/浅色/系统主题、中英文及动态效果。系统“减少动态效果”优先；关闭动效会覆盖新页面、旧报告评分仪表和持仓饼图的动画。

原分析、问股、选股、持仓、AI 建议、回测、告警、数据中心与设置入口继续使用现有模块。新增研究入口的加载和切换不启动模型、通知或分析任务；既有任务按钮仍遵循原配置。

仓库根目录启动命令：

```powershell
.\scripts\local-web.ps1 Status
.\scripts\local-web.ps1 Start
```

前端修改后使用 `Build`，后端修改后在任务空闲时 `Stop` 再 `Start`。完整隔离环境说明见 [本地 Windows 使用说明](local-windows.md)。

## 视觉与交互

保留 React、Tailwind v4、Motion、Recharts、next-themes 与现有组件。新增一个覆盖现有 HSL 变量的石墨/纸灰主题层，没有迁移 UI 框架或安装新动画库。

- 原创开口轨道标识、一次性品牌光扫与细线轨道装饰。
- 桌面可折叠导航、活动项细光线、键盘焦点和跳到主要内容入口。
- 非对称研究主面板、来源侧栏、四资产选中反馈、研究假设关系 SVG。
- 路由与研究视角入场只在切换时运行；关闭动效或系统偏好生效时立即呈现内容。
- 历史价格图使用真实返回数据，无报价数值递增或价格曲线入场动画；失败和切换资产会撤下旧图。

采用现有项目渐进升级方法：保留业务组件、通过共享主题和外壳提高一致性。参考现有 [Motion](https://github.com/motiondivision/motion) 的交互与减少动效能力，以及 [Radix](https://github.com/radix-ui/primitives) 的无样式交互思路；本期未复制第三方组件源码或素材。React Bits 的 [MIT + Commons Clause](https://github.com/DavidHDev/react-bits/blob/main/LICENSE.md) 不能按纯 MIT 处理，因此本期未引入。素材与开源库后续逐项登记来源、版本和许可。

## 数据证据与 API 变化

真实免费源探测已成功返回腾讯源 `510300` 的 39 条日线，最新 bar 日期为 2026-10-09。成交额为空、实际复权口径未知、最终 bar 完整性未独立核验。详见 [免费数据验证记录](data-source-local-verification.md)。这次独立探测不会自动把 Web 来源概览标记成健康。

`GET /api/v1/stocks/{stock_code}/history` 保留旧字段，增加 `source`、`fetched_at`、`status`、`warnings`、`adjustment`。`fetched_at` 是请求完成时间，不是行情时点。`available` 仅表示返回的行与字段完整，新鲜度仍未验证。

可选数值 NaN/Inf 转为 JSON `null`，合法零值保留。必需 OHLC 非有限、非正或不满足高低价包络的行跳过，并报告 `partial` 与数量；不生成零价。前端严格拒绝错误日线周期，过滤非法日期和重复日期。来源失败返回 `unavailable`，空结果返回 `empty`。个股档案的历史块同步保留证据与限制，不将未验证的历史数据标为新鲜。

本期尚无宏观事件 API、BTC 现货适配器、黄金现货/期货合约、全资产统一排序与组合回测。研究关系图是待检验的问题框架，不能当作当前宏观结论。

## 验证记录

执行记录与最终结果见 [阶段一实施计划](superpowers/plans/2026-10-09-workbench-foundation.md)。浏览器截图和一次性测试记录放在被忽略的 `local/`，不合入产品源码。

最终验收：前端全量 **1,404 通过 / 2 跳过 / 0 失败**（两个 worker）；历史质量与完整档案 API **80 项通过**；构建通过。Lint 无错误，保留一处原有选股页面 hook 依赖警告。桌面深浅色、375px 手机、减少动效、笔记切换与离开提醒、日线样本成功/失败撤图和来源刷新失败均通过浏览器验收。

实际登录页验收只读取鉴权状态，没有重置密码或登录。登录后的研究 UI 验收使用独立浏览器上下文及固定接口样本，不代表行情联网成功；真实免费行情成功由独立探测证明。生产模型、通知、实盘、Electron 与广东服务器部署均未在本阶段验收。
